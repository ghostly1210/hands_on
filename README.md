HandsOn 👋

HandsOn es una aplicación diseñada para que personas de distintas edades aprendan lenguaje de señas de forma interactiva a través de la imitación física y un sistema de validación para garantizar un aprendizaje preciso, efectivo y al mismo tiempo divertido. 

💡Características Principales 
- Aprendizaje Multigeneracional: Interfaz intuitiva adaptable para niños, jóvenes y adultos.
- Método de Imitación: Enseñanza guiada a traves de íconos interactivos, GIFs ilustrativos y videos de corta duración.
- Sistema de Verificación Inteligente: Validación (mediante la cámara del dispositivo) para asegurar que el usuario realice la seña de forma correcta.

💻 Tecnologías Utilizadas 
- Fronted: Android Studio (para compatibilidad con Andorid). 
- Inteligencia Artificial: Aún por definir
- Backend: Aún por definir
- Base de datos: Aún por definir
